# Decisions log

| # | Decision | Why | Alternatives considered |
|---|---|---|---|
| D1 | **Python 3.13** venv instead of the planned 3.11 | Only 3.13 was installed on the dev machine, and all dependencies ship 3.13 wheels. Setup scripts accept ≥ 3.11 | Installing 3.11 would have cost time and gained nothing |
| D2 | **CPU torch** even though an RTX 2050 is present | bge-small embeds a whole agreement in well under a second on CPU. The CUDA wheel is ~2.5 GB, and the GPU is better left to Ollama | CUDA torch |
| D3 | Default model **gemma4:e4b** | Benchmarked at 14.4 tok/s, above the 8 tok/s threshold. Better at following schemas and picking quotes | E2B (65 tok/s) is the configurable fast option |
| D4 | **One LLM call per category** with ≤3 clauses (~3.5k chars) | Keeps each prompt under ~1.5k tokens: faster, more focused, and the model is less likely to mix clauses | Whole-document prompt (slow, unfocused, larger quote-hallucination surface); per-clause calls (too many calls) |
| D5 | **Verifier snaps quotes to the real span** | Even a fuzzy-accepted quote is displayed as verbatim document text, so model text can never appear as a quote | Showing the model's quote when it is "close enough" |
| D6 | Fuzzy threshold **partial_ratio ≥ 90 with ≥ 85% coverage** | Tolerates PDF extraction noise (hyphenation, ligatures, spacing) but rejects paraphrases. Tests cover typos, paraphrase and fabrication | Exact only (too brittle for PDFs) |
| D7 | **Numbers in explanations must be grounded** | Sentences with digits not present in the quote or rule-extracted facts are removed, which stops invented amounts and dates | Trusting the model |
| D8 | **Verdict scrubber** on all model text | A defence in depth, alongside the prompt rule, against "this clause is illegal/unenforceable/fair" | Prompt-only |
| D9 | **Rules first, then LLM** for question classification | Verdict and out-of-scope questions are caught with high precision and no latency, and the LLM handles the rest. If the LLM is down, the default is `document_fact`, which is safe because answers still need verified quotes | LLM-only |
| D10 | Silent answers need a **topic-overlap check** | Stops answers like "pets aren't allowed" being drawn from a "residential use only" clause. If no salient question term (or synonym) appears in the cited quotes, the answer becomes "The document is silent on this" | Trusting `found=true` |
| D11 | **Injection: flag + remove before the model sees it** | Removing the text, the delimiters and the system prompt each work independently. The user still sees the flagged text | Flag-only |
| D12 | **One-sided wording upgrades a finding to CONCERN** (from `one_sided_patterns.json`) | Gemma tended to label everything "explicit", so a deterministic rule makes labelling consistent | Prompt-only |
| D13 | **Global de-duplication** of findings by quote overlap; the stronger severity or concern wins | Otherwise the same clause appears under 3–4 categories | Per-category de-duplication |
| D14 | **Rule-based fallback findings** (amounts, notice periods) | Useful output when Ollama is down, and they fill recall gaps; marked `source: rules` | No fallback |
| D15 | **netguard** patches Python sockets in-process | Simple and testable, and catches every library using Python networking. Limitations are documented in PRIVACY.md | OS firewall rules (not portable); Docker `--network none` (Phase 2) |
| D16 | Knowledge-file loaders accept a plain list **or** `{"_placeholder": true, "items": [...]}`, and fall back to built-in defaults | Teammate files may be missing or partial, and the app must never crash on them | Strict schema |
| D17 | DOCX/TXT "pages" are ~3,000-character sections | These formats have no fixed pagination. The UI notes this | Reporting no page |
| D18 | Root `app.py` is a thin launcher for `lexlocal/app.py` | Keeps the empty `app.py` stub from the initial commit as the entry point (`streamlit run app.py`) | Moving the entry point |
| D19 | `dateparser` is pinned but not used yet | It is reserved for normalizing dates in the Phase 2 structured extraction table | Remove it |
| D20 | **No emojis anywhere**; severity shown as a text label plus a small CSS dot (`aria-hidden`) | Emojis render differently per OS and look informal. Text keeps meaning without colour | Emoji icons (Phase 1) |
| D21 | **Warm off-white editorial theme** (`lexlocal/ui/theme.py`, `.streamlit/config.toml`), system serif headings and system sans body | No web fonts, so nothing is downloaded. All text/background pairs are at least 6.2:1 (WCAG AA) | Bundling a web font (adds weight and licence notes) |
| D22 | **Favicon is a local PNG** (`lexlocal/ui/assets/favicon.png`), not an emoji or `:material/...:` icon | Streamlit loads emoji and Material-icon favicons from external URLs | Default Streamlit favicon |
| D23 | **Pure-CSS splash** (per-letter 3D roll, fade at 2.0 s), shown once per session, hidden under `prefers-reduced-motion`, `aria-hidden` | No JS dependency or CDN, and it never replays on reruns | React/motion component |
| D24 | `server.fileWatcherType = "none"` | The watcher imported every `transformers` submodule on start, which logged dozens of torchvision tracebacks and slowed startup | Leaving the default |
| D25 | Docs run `python -m streamlit` instead of the `streamlit` launcher | Venv console launchers hard-code the venv's original path and break if the project folder moves (this happened on the dev machine) | — |
| D26 | **No-external-assets check is automated** with headless Edge over CDP: every request the page makes is logged and must be loopback. A manual Wi-Fi-off run is still recommended before the demo | Toggling Wi-Fi from the dev agent would cut its own session. CDP logging is stricter, because it shows each URL | Wi-Fi-off only |
| D27 | **Result views are a segmented control, not `st.tabs`** | Streamlit tabs can't be switched from code, so "View in document" and the clause outline could not jump. Rendering only the active view is also faster | Tabs plus a "now open the Document tab" hint |
| D28 | **PDF highlight by word-sequence match** (`report/pdfview.py`), merged into one band per line | `search_for` misses quotes that cross line breaks. Matching word tokens and ignoring punctuation and case survives PDF layout, while altered numbers still fail to match | Character search; drawing over extracted text |
| D29 | PDF bytes are kept **in session memory only** (for page rendering) and cleared with the document. Rendered pages are not cached | `st.cache_data` would outlive the session and survive **Clear document** | Caching renders |
| D30 | A truncated LLM reply (`done_reason == "length"`) is retried with **1.75 times the token budget**, not a repair prompt. Summary budget raised from 600 to 800 | E2B summaries hit the 600-token cap and failed JSON parsing twice | Repair prompt (cannot fix truncation) |
| D31 | **Key-terms table from rule facts only** (`extract/structured.py`). Each fact is filed by keywords near it in its own sentence. Facts that fit no field are left out, and expected fields with no match show "Not found by the rules" | Values are exact spans, so they are verified by construction. A missing row is safer than a guessed one | Asking Gemma to fill the table (needs verification and adds latency) |
| D32 | Rule fixes found while building the table: uppercase "AND Ms. X" second party; governing-law place names kept capitalised with `(?-i:...)`; "11 (eleven) months" durations; durations de-duplicated per sentence (term and lock-in can share a value) | Each one caused a wrong or missing row on the samples. All covered by `tests/test_structured.py` | — |
| D33 | **Conflicts are rules first** (figures vs words, "11 (twelve)", the same key term with two values, term vs dates via `dateparser`, lock-in at least as long as the term, two notice periods for the same party), plus **at most `LEXLOCAL_PAIRWISE`=2 Gemma clause-pair checks** that require both quotes to verify | Rules are exact and add no latency. The model only checks pairs the rules did not cover. Zero false conflicts on the three consistent samples | Gemma over all pairs (O(n²) calls) |
| D34 | **"Unusual" has three bases**: one-sided phrases, asymmetric notice between opposite parties (at least 2x), and bge-small cosine **< 0.68** to the nearest of ~35 reference clauses (`knowledge/standard_clauses.json`, written by the team). The preamble, bare headings and injection-flagged text are skipped | On the samples, balanced clauses scored 0.75-0.96 and one-sided ones 0.60-0.69. Zero flags on `rental_clean` | Embedding distance alone (it flags topics with no reference clause) |
| D35 | All conflict and unusual explanations are **fixed templates** (rules) or verdict-scrubbed (model). The wording is "worth asking about", never a legality, validity or fairness conclusion. Tested for verdict words | Constraint 3 | Free-form model explanations |
| D36 | **Confidence from signals** (quote match, rule-LLM agreement, category fit, self-consistency on up to `LEXLOCAL_SELF_CONSISTENCY`=2 high-severity categories at temperature 0.7, OCR page confidence), weighted mean times a kind prior | Each signal is independent and explainable. The card's help text lists them | Model self-reported confidence (not calibrated) |
| D37 | **Calibration kept the default weights and thresholds (0.85/0.65)**: 51 hand-labelled E4B findings, 92% accurate. The 4 errors had the same signal values as correct findings, and the best grid weights improved Brier only from 0.074 to 0.072 | Refitting on 51 items with no separation would be fitting noise. The limitation is stated in EVALUATION.md: confidence measures anchoring, not paraphrase quality | Using the grid-searched weights |
| D38 | **Jurisdiction = state detection plus topic notes, nothing more.** The state comes from governing law naming a state, else the courts' city, else the place of signing (city-to-state table). Each note is general, ends with "a lawyer who practises in <state> can confirm", and contains **no digits** (enforced by a test) | Constraint 3: no statutory limits stated as fact and no conclusions. Being specific about the state still makes the escalation more useful | Encoding state rent-control limits (out of date quickly and would read as advice) |
| D39 | **Vault for the only disk writes (OCR)**: per-session `mkdtemp`, Fernet with an in-memory key, zero-overwrite then delete on Delete document, Panic wipe, session garbage collection (`weakref.finalize`) and `atexit` | Streamlit has no reliable "session ended" callback. A finalizer on an object referenced only by session state runs when Streamlit discards that state | Writing temp files unencrypted; relying on the OS temp cleaner |
| D40 | **Panic wipe** clears every session key except the splash flag, wipes the vault, clears `st.cache_data`, and bumps the uploader's key so the uploaded file is dropped too | Otherwise the next rerun would re-parse the still-attached upload | Clearing only the document keys |
